                    FoodFleet
Web-Based Food Ordering System with ML-Powered Recommendations
---Overview:
FoodFleet is a full-stack web-based food ordering platform designed to simulate real-world online delivery systems.
The system integrates a Machine Learning–based recommendation engine to provide personalized food suggestions based on user preferences, age group, and allergy constraints.
This project demonstrates practical implementation of:
Full-stack web development
Authentication workflows
Secure OTP-based password recovery
Database integration
Machine Learning recommendation logic

---Tech Stack:
Frontend:
HTML5
CSS3
JavaScript
Backend:
PHP
MySQL
Machine Learning Module:
Python
Association Rule Learning (Apriori Algorithm)
Other Integrations:
PHPMailer (SMTP-based OTP verification)
Session management
Distance-based delivery calculation logic

---Core Features
User Management:
User registration & login
Session handling
OTP-based password recovery
2-minute order cancellation window
Food Ordering System:
Dynamic menu display
Add to cart with quantity control
Allergy-aware filtering
Age-based food recommendations
Distance-based delivery charge calculation
ML Recommendation Engine:
Implements Association Rule Mining
Suggests frequently paired food items
Personalized suggestion logic based on user order history

---Machine Learning Implementation
The recommendation system uses Association Rule Learning (Apriori Algorithm) to:
Analyze transaction history
Identify frequently bought itemsets
Generate confidence-based recommendations
This improves:
Cross-selling strategy
User engagement
Order value optimization
